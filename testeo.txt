> Como lo probamos:

  Esta es una guía detallada paso a paso para probar la aplicación de punta a punta en tu entorno local.
  Esta guía te permitirá verificar los roles, el aislamiento de datos y los controles de seguridad que hemos construido en el sistema.
  ──────
  ### Paso 1: Preparar el Entorno e Iniciar Contenedores

  Abre una terminal PowerShell o CMD en la ruta  C:\Proyectos\crm-lawfirm  y ejecuta:

  1. Crear archivo de configuración local:
    copy .env.example .env
  (El sistema vendrá preconfigurado por defecto para funcionar localmente de inmediato).
  2. Levantar los contenedores:
    docker compose up --build -d
  Esto compilará y levantará de forma aislada la Base de Datos Postgres, el Backend FastAPI, el Frontend React y el Proxy Nginx en segundo plano.
  3. Ejecutar las migraciones de base de datos:
    docker compose exec backend alembic upgrade head

  4. Sembrar el administrador inicial:
    docker compose exec backend python seed_admin.py
  (Crea al usuario  admin@estudio.com  con la contraseña  AdminLawFirm2026!  de forma segura).
